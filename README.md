# تحليل أداء السائقين
## الرؤية الحديثة | New Vision LG

> برنامج مستقل لتحليل بيانات التوصيل — يعمل بدون إنترنت نهائياً بعد التثبيت

---

## ما هو هذا البرنامج؟

بدل فتح ملف HTML في المتصفح، هذا برنامج `.exe` حقيقي على ويندوز يقرأ
ملف Excel مباشرةً بلغة **Rust** — أسرع وأدق من أي متصفح.

| المقارنة | HTML في المتصفح | هذا البرنامج |
|---------|----------------|-------------|
| قراءة Excel | SheetJS (JavaScript) | Rust (calamine) |
| السرعة | متوسطة | 5-10× أسرع |
| دقة الوقت | خطر UTC+3 | ✅ لا timezone |
| يعمل offline | بعد تحميل أول | ✅ دائماً |
| حجم البرنامج | ملف HTML فقط | ~8-15 MB |

## المتطلبات (مرة واحدة فقط)

### 1. Microsoft C++ Build Tools
مطلوب لبناء Rust على ويندوز.

**تحميل:** https://aka.ms/vs/17/release/vs_BuildTools.exe

عند التثبيت، اختر: **"Desktop development with C++"**

---

### 2. Rust
لغة البرمجة المستخدمة للقراءة السريعة.

**تحميل:** https://rustup.rs  
نزّل `rustup-init.exe` وشغّله — اقبل كل الإعدادات الافتراضية.

---

### 3. Node.js
مطلوب لأدوات Tauri فقط.

**تحميل:** https://nodejs.org  
اختر نسخة **LTS** (الأكثر استقراراً).

---

## التثبيت (مرة واحدة)

```
1. افتح مجلد المشروع
2. شغّل setup.bat بضغطة مزدوجة
3. انتظر 3-5 دقائق (تحميل مكتبات Rust)
4. ابحث عن ملف التثبيت في:
   src-tauri\target\release\bundle\msi\
```

ثبّت الـ `.msi` وسيظهر البرنامج في قائمة ابدأ.

---

## تشغيل للتطوير (بدون تثبيت)

```bat
dev.bat
```

أو من Command Prompt:
```
npm run dev
```

│   ├── capabilities/

│   └── build.rs
│
├── package.json            ← إعدادات Node.js
├── setup.bat               ← تثبيت تلقائي

## التحديث

عند تعديل `index.html`:
```
npm run build
```
أو اشغّل `setup.bat` من جديد.

عند تعديل `main.rs` (Rust):
```
npm run build
```
